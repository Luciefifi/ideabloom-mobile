# IdeaBloom Mobile

> Your ideas, in full bloom.

The future mobile app for **IdeaBloom**, a personal workspace for capturing ideas and growing them into
projects, tasks, milestones, notes and resources.

## Status

📋 **Planned, not yet in development.** Mobile work starts after the web app
([ideabloom-web](https://github.com/Luciefifi/ideabloom-web)) is sufficiently complete.

## Planned tech stack

- React Native + [Expo](https://expo.dev/)
- TypeScript
- The existing [ideabloom-api](https://github.com/Luciefifi/ideabloom-api) REST backend. Business logic
  is not duplicated in the app.

An architecture plan will be added in `docs/ARCHITECTURE.md`.
